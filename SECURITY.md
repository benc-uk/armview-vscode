# Security Policy

## Supported Versions

The following table describes which versions of this extension receive security updates. The current stable series is 0.4.x (latest patch is listed in `package.json`).

| Version  | Supported          |
| -------- | ------------------ |
| 0.4.x    | :white_check_mark: |
| < 0.4.0  | :x:                |
